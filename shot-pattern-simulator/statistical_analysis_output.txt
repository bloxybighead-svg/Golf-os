1. SIGNIFICANCE TESTS: simulated (calibrated profile) vs real shots
==============================================================================
H0 for the t-test: the two samples have the same mean.
H0 for the KS test: the two samples are drawn from the same distribution
(KS is the stricter test -- it checks the whole shape, not just the mean).
p < 0.05 => reject H0 => simulator's output measurably differs from real.
NOTE: this section is IN-SAMPLE (profile fit on these same shots). See

3. POWER ANALYSIS: how many real shots before the CI stabilizes?
==============================================================================
For Driver and 7-Iron: for each n, draw 200 random subsamples of n real
shots (without replacement), bootstrap a 95% CI on each (1,000
resamples), and average the CI half-width over the 200 subsamples.
Averaging removes the noise a single random subsample would add. The
dashed line is the textbook normal-theory half-width 1.96*s/sqrt(n),
using the club's full-sample SD.

5. HELD-OUT VALIDATION (fit on some sessions, test on unseen sessions)
==============================================================================
Whole SESSIONS are held out (5-fold, seeded shuffle of the
19 full-swing sessions), because shots within a session are correlated.
For each fold: fit a profile on the training sessions only, simulate
20x as many shots as the held-out fold has per club, then pool across
folds and run the same t / KS tests against the held-out real shots.
Clubs with < 10 training shots in a fold get no profile there, so those
held-out shots are skipped (counted below).
